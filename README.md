# Plantilla Ecommerce HTML-CSS

## Descripción
Plantilla para Ecommerce, utilizando HTML, CSS, Bootstrap y simulando productos y categorías utilizando la API DummyJSON

## Demo
- Sitio desplegado: https://manuelyaneza.github.io/plantilla-ecommerce-HTML_CSS/

## Cómo correr localmente

## Cómo correr localmente
```bash
git clone https://manuelyaneza.github.io/plantilla-ecommerce-HTML_CSS/
cd plantilla-ecommerce-HTML_CSS
#En Windows
start index.html
#En MacOS
open index.html
#En Linux
xdg-open index.html
#Desde VS Code
Instalar la extensión "Live Server"
Hacer click derecho en index.html
Click a "Open with Live Server"
```
## Estructura del proyecto

## Stack

- HTML5 semántico
- Bootstrap 5 (vía CDN)
- CSS custom propio (paleta, tipografía, ajustes)
- JavaScript vanilla
